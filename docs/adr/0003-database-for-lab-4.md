# 0003. Database for Lab 4 / База данни за Упражнение 4

**Status / Статус:** Accepted

## Context / Контекст

Без `DATABASE_URL` бележките се пазят в паметта и се губят при рестарт. За Упражнение 4 ни трябва постоянно хранилище, което да работи в контейнер до приложението.

## Options / Варианти

1. **PostgreSQL**
   - Приложението вече го поддържа (`psycopg`, `PostgresNoteRepository`).
   - Има официален Docker образ; стандартен избор в индустрията.
   - Още един контейнер за пускане и поддръжка.
2. **SQLite**
   - Един файл, без отделен сървър.
   - Приложението няма код за SQLite; трябва да се пише.
   - Неудобно при няколко копия на приложението.
3. **Само в паметта (без база)**
   - Нищо за настройване.
   - Данните се губят при всеки рестарт.

## Decision / Решение

Използваме PostgreSQL в отделен контейнер. Приложението се свързва чрез `DATABASE_URL`, например `postgresql://notes:secret@db:5432/notes`.

## Consequences / Последствия

- Бележките оцеляват при рестарт на приложението.
- `/ready` започва реално да проверява връзката с базата (503, ако я няма).
- Трябва да пазим паролата извън кода и да мислим за backup.
