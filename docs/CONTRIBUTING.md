Contributing
Клони
T<номер>, например T0.4. Един клон = една задача.

Комити
Кратко изречение на английски: Add CODEOWNERS.

Pull Requests
Всяка промяна в main минава през PR.
Нужно е 1 одобрение от партньора (Code Owner).
PR-ът е свързан с Issue, има label и milestone.
След merge клонът се изтрива.

Branching strategy: GitFlow - отделни клонове develop, release и hotfix за по-строг контрол на изданията.
