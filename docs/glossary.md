# Glossary / Речник

> Keep the table in alphabetical order. One term per row. / Пазете таблицата по азбучен ред. Един термин на ред.

| Term / Термин | Meaning / Значение |
|---|---|
| Artifact | The built output of a pipeline, e.g. a package or an image. / Резултатът от изграждането, напр. пакет или образ. |
| Branch | A separate line of work in a repository. / Отделна линия на работа в хранилището. |
| CI | Continuous integration: every change is built and tested automatically. / Всяка промяна се изгражда и тества автоматично. |
| Commit | A saved snapshot of changes with a message. / Записано състояние на промените със съобщение. |
| Container | An app packaged with everything it needs to run in isolation. / Приложение, пакетирано с всичко нужно, за да работи изолирано. |
| Deployment | Putting a version of the service where users can reach it. / Поставяне на версия на услугата там, където потребителите я достигат. |
| Health check | An endpoint that says whether the service is alive. / Адрес, който казва дали услугата е жива. |
| Issue | A task, bug or idea tracked on GitHub. / Задача, бъг или идея, проследявани в GitHub. |
| Merge | Joining the changes of one branch into another. / Обединяване на промените от един клон в друг. |
| Pipeline | An automated sequence of steps: build, test, deploy. / Автоматична поредица от стъпки: изграждане, тестове, внедряване. |
| Pull request | A proposal to merge one branch into another, with review. / Предложение един клон да се слее в друг, с ревю. |
| Release | A published version of the service, ready for users. / Публикувана версия на услугата, готова за потребителите. |
| Rollback | Returning to the previous working version after a failure. / Връщане към предишната работеща версия след проблем. |
| Runner | A machine that executes the jobs of a pipeline. / Машина, която изпълнява задачите от pipeline. |
| Tag | A fixed name for a specific commit, e.g. v0.2.0. / Постоянно име на конкретен commit, напр. v0.2.0. |
| Version | A named state of the service, e.g. 0.2.0. / Именувано състояние на услугата, напр. 0.2.0. |
